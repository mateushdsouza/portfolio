# Portfólio — Mateus Henrique de Souza

Portfólio pessoal de um estudante de Engenharia de Software, com foco em oportunidades de estágio remunerado e desenvolvimento júnior.

## Projetos selecionados

- ParceiroAuto web: projeto em equipe com Spring Boot, Angular e PostgreSQL.
- ParceiroAuto desktop: gestão financeira com Java Swing e JPA/Hibernate.
- Wikimon: consumo da PokéAPI, comparação de atributos e favoritos locais.

O site também apresenta formação, contato e estudos em andamento, incluindo o curso Fullstack com React e Node.js.

## Executar localmente

Abra [index.html](index.html) no navegador ou sirva esta pasta com um servidor estático. Não há dependências para instalar ou etapa de build.

HTML, CSS e JavaScript sem framework, com tema claro/escuro, filtros, detalhes em modal e menu móvel. A preferência de tema usa localStorage quando disponível. Os links de contato abrem e-mail e LinkedIn; não há backend de envio.

## Arquivos

- [index.html](index.html): conteúdo e estrutura.
- [styles.css](styles.css): estilos e responsividade.
- [app.js](app.js): tema, menu, filtros e detalhes.
- [assets/](assets/): favicon e captura real do comparador Wikimon.

Ao atualizar um projeto, mantenha o cartão em index.html e os detalhes em app.js coerentes.
